# HAN ATLAS — GitHub Pages файлдары

Бұл архивтегі файлдар сайттың жарияланатын негізгі папкасына арналған. GitHub репозиторийінде сайт файлдары тікелей түбірде жарияланса, архивті түбірге ашыңыз. Егер Pages workflow `dist` папкасын жарияласа, осы файлдардың бәрін `dist/` ішіне салыңыз.

## Жариялау
1. GitHub-та HAN репозиторийін ашыңыз.
2. Жариялау папкасындағы ескі файлдарды осы архивтегі файлдармен ауыстырыңыз. `assets/` папкасын толық күйінде сақтаңыз.
3. Commit changes жасаңыз. GitHub Pages жаңартылған бетті жариялайды.
4. Кэште ескі стиль қалса, бетті қатты жаңартыңыз: Mac-та `Cmd + Shift + R`.

## Басты бетте не бар
`index.html` — карта бірінші экранда ашылатын басты бет. Оқиға сүзгілері, карта, белгі туралы түсіндірме және негізгі зерттеу бөлімдеріне сілтемелер бір жерде.

## AI
AI чатының Cloudflare Worker адресі `assets/ai-client.js` ішінде әлі placeholder. Жаңа Worker-ді жариялап, нақты URL-ін сол тұрақтыға енгізбейінше AI жауап бермейді.
